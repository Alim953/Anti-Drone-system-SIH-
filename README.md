# Anti-Drone-system-SIH-

Problem Statement : High Altitude Anti Drone System 


Solution:
TRINETRA is a robust and adaptive high-altitude anti-drone system designed to maintain reliable detection, tracking, and operation under extreme environmental conditions. The system integrates a wind-stable three-leg structure, vibration suppression, adaptive thermal management, solar-Li-ion power management, and cold-resistant electrical interconnects to ensure mechanical and electrical reliability at high altitude. AI-assisted multi-sensor processing enables accurate drone detection, tracking, and classification, while precision pointing compensation maintains sensor accuracy despite thermal drift, vibration, and cable torque. Secure communication protects critical system and target data, and continuous health monitoring enables early fault detection and predictive maintenance. Together, these technologies provide a stable, energy-efficient, precise, and resilient anti-drone platform optimized for high-altitude deployment.
